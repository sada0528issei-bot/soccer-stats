# 出場時間ランキング自動集計スクリプト

東京都大学サッカー連盟の公式サイトから、各選手の出場時間を自動計算してCSVに出力するツールです。

## 1. 事前準備(初回のみ)

パソコンのターミナル(コマンドプロンプト)で以下を実行してください。

```
pip install playwright beautifulsoup4
playwright install chromium
```

- `playwright install chromium` は、Playwrightが自動操作用に使う専用のブラウザをダウンロードするコマンドです。少し時間がかかります。
- Pythonが入っていない場合は、先に https://www.python.org/ からインストールしてください。

## 2. 実行方法

`scrape_stats.py` と同じフォルダで、ターミナルから以下を実行します。

```
python scrape_stats.py
```

初回は `HEADLESS = False` の設定になっているため、実際にブラウザが立ち上がり、試合が自動でクリックされていく様子が見えます。正しく動いていることを確認できたら、`scrape_stats.py` の中の

```python
HEADLESS = False
```

を

```python
HEADLESS = True
```

に変更すると、ブラウザ画面を表示せずバックグラウンドで高速に実行できます。

## 3. 出力されるファイル

- `raw_playing_time.csv` … 試合ごとの生データ(1行 = ある選手のある1試合の出場記録)
- `playing_time_ranking.csv` … 選手ごとに全試合分を合計した、出場時間ランキング

Excelなどで開けば、そのままソートしてランキングを作れます。

## 4. うまく動かない場合のヒント

- **試合が0件と表示される**: `MATCH_ROW_SELECTOR` の指定が現在のページ構造と合っていない可能性があります。サイトの表示形式が変わっていないか、開発者ツールで確認してください。
- **一部の試合だけ「想定外の構造」と表示される**: その試合だけ表示形式が違う可能性があります(例: 不戦勝、中止試合など)。該当の試合URLと状況を教えていただければロジックを調整します。
- **出場時間の数字が合わない気がする**: `raw_playing_time.csv` を開いて、該当選手・試合の行を確認し、公式サイト上の表示と見比べてみてください。ズレがあれば教えてください。
- **対象シーズンを変えたい**: `scrape_stats.py` の `SCHEDULE_URL` を、対象年度・シリーズのURLに書き換えてください。

## 5. 出場時間の算出ルール

- フル出場: 90分
- 途中交代(▼): 表示されている交代時刻をそのまま採用(「HT」は45分、「90+X」は90分として扱う)
- 途中出場(▲): (90分 − 交代時刻)を採用(「HT」は45分、「90+X」は0分として扱う)

このルールは、Jリーグ公式記録の考え方を参考にしています。
